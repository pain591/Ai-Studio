# Ai-Studio

## Shanghai Plot Atlas (prototype)

A 3D map of Shanghai that turns messy planning data into a clear answer for any plot: what
can be built there, how big and how tall, and which rules apply. The first district is
Xuhui.

- `mockup/index.html`: clickable UI prototype (deck.gl, no build step). It loads `mockup/data.js`.
- `mockup/build_data.py`: builds `data.js` from OpenStreetMap and DataV downloads.
- `docs/shanghai-data-sources.md`: research notes on regulations, plot-level data sources, map data and legal limits.

Planning values in the prototype are illustrative placeholders. Map data
© OpenStreetMap contributors (ODbL).
